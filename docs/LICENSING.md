# Licensing

MoraLink uses two main licenses because the repository contains both original software and data derived from another dataset.

## Apache-2.0

The root [`LICENSE`](../LICENSE) applies to:

- source code;
- prompts;
- configuration files;
- tests; and
- original documentation.

## CC BY-NC 4.0

The benchmark fables and original morals come from [MORABLES](https://huggingface.co/datasets/cardiffnlp/Morables). Its dataset card identifies the source data as CC BY-NC 4.0.

The MoraLink benchmark data, group mapping, generated summaries, and data-specific metadata are therefore released under [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/). Reusers must provide attribution, indicate changes, and use these artifacts only for noncommercial purposes.

## Materials not included

MoraLink does not redistribute model weights, STORAL, or TF1-EN-3M. Those resources keep their original licenses and terms. Anyone who downloads a model or reruns summary generation must also follow the model provider's current terms.

See [`NOTICE`](../NOTICE) for source attribution and the generator identifiers used for the fixed summary outputs.
